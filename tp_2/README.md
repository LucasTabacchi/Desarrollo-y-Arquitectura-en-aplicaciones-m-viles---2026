# Desarrollo y Arquitectura en aplicaciones móviles - TP 2

Trabajo Práctico 2 de la materia Desarrollo y Arquitectura en aplicaciones móviles.

## Configuración y ejecución

1. Instalar dependencias:
   ```bash
   npm install
   ```
2. Ejecutar la aplicación:
   ```bash
   npm run start
   ```

## Tecnologías
- [Expo](https://expo.dev/)
- [React Native](https://reactnative.dev/)
